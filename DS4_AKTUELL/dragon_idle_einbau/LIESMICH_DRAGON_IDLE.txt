CORRIDOR SLAYER // DRAGON IDLE ANIMATION - FERTIGES PAKET
==========================================================

INHALT
------
main.py                              -> ersetzt deine DS4\main.py
enemys\enemy_dragon_idle_0.png ... _7.png  -> gehoeren in DS4\enemys\
LIESMICH_DRAGON_IDLE.txt             -> diese Anleitung
tools\extract_dragon_frames.py       -> optional, zum Selber-Extrahieren

WAS WIRD EINGEBAUT?
-------------------
Dein Sprite-Sheet (dragon_idle_sheet_8frames_1024x420.png) wurde in 8
einzelne Frames zerlegt (je 898x359 px, transparenter Hintergrund beibehalten).
Die neue main.py spielt sie automatisch als Idle-Animation ab:

  - 8 FPS, Endlosschleife (ANIM_FPS in main.py veraenderbar)
  - alle Drachen im Lauf synchron
  - Rotation Richtung Schiff wie bisher
  - In-Game-Groesse 70x27 px (alter statischer Drache: 70x26 - fast identisch)

OHNE RISIKO: Fehlen die Frames oder du loeschst sie wieder, zeigt das
Spiel wie bisher das statische enemy_dragon.png. Sonst aendert sich
NICHTS - Kampagne, Idle-Modus und alle anderen Gegner bleiben unberuehrt.

INSTALLATION (2 Datei-Aktionen)
-------------------------------
1. SICHERHEIT: Kopiere deine bisherige main.py weg (z.B. als main_sicherung.py).
2. main.py  -> in deinen Spielordner DS4 kopieren, alte Datei ersetzen.
3. Ordner enemys  -> die 8 enemy_dragon_idle_*.png MUESSEN direkt in
   DS4\enemys\ liegen (NICHT in enemys\enemy_dragon\idle\ - der
   Spielordner DS4\enemys\ ist der richtige Ort).
4. Spiel starten: Der Drache animiert sich im PvE-/Idle-Kampf.

BONUS
-----
Das System ist allgemein: Legst du spaeter fuer andere Gegner Frames
im Format enemy_<typ>_idle_<nr>.png (Nummerierung ab 0) in enemys\ ab,
animiert das Spiel diese ebenfalls automatisch - ohne weitere Code-
Aenderung. Das Original-Sheet kann im Spielordner bleiben oder
geloescht werden; das Spiel benoetigt nur die 8 einzelnen Frames.

TECHNISCHE PRUEFUNG (bestanden)
-------------------------------
- 8 Frames geladen, alle gleich gross, Per-Pixel-Alpha
- Animation laeuft und loopt sauber (t=0 / 1000ms / 2000ms -> Frame 0)
- Statische Fallbacks unveraendert (skitter, unbekannte Typen)
- enemy_dragon.png / enemy_dragon_closed.png unveraendert
